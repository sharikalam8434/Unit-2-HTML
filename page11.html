HTML Hyperlinks

1. HTML Links - Syntax

HTML links are hyperlinks. They allow users to move from one page to another.

The <a> tag defines a hyperlink. 

<a href="url">link text</a>
Visit ITMBU

2. Target Attribute

The target attribute specifies where to open the linked document.

Example of opening a link in a new tab: 

<a href="https://itmbu.ac.in" target="_blank">
        Visit ITMBU
</a>
Visit ITMBU

Common target values are _self, _blank, _parent and _top.

3. Absolute and Relative URLs

Absolute URL

An absolute URL uses the complete web address.

Relative URL

A relative URL points to a page or file within the current website.

4. Image as a Link

To use an image as a link, place the <img> tag inside the <a> tag.

5. Link to an Email Address

Use mailto: inside the href attribute to create an email link.

6. Button as a Link

An HTML button can be used as a link with JavaScript. 

<button onclick="document.location='HTML MAIN PAGE.html'">
    HTML Main Page
</button>

7. Link Titles

The title attribute specifies extra information about an element, often shown as a tooltip when the mouse is moved over the link.
