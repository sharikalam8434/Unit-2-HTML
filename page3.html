HTML Elements

What is an HTML Element?

An HTML element is everything from the start tag to the end tag.

Basic Syntax

 
<tagname>Content</tagname>

Parts of an HTML Element

1. Start Tag

The start tag marks the beginning of an HTML element.

2. Element Content

The content is the information written between the start tag and the end tag.

3. End Tag

The end tag marks the end of an HTML element.

Examples

 
<h1>My First Heading</h1>
<p>My first paragraph.</p>

Empty Elements

Some HTML elements have no content and no end tag. These are called empty elements.

Example:

<br>

The <br> element is used as an empty element.
