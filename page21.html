XHTML

What is XHTML?

XHTML is the strict, XML-based version of HTML. Unlike HTML5, XHTML does not tolerate syntax shortcuts.

Core Rules of XHTML

1. Strictly Lowercase Tags

All tags must be written in lowercase. 

<body>
    <p>This is correct</p>
</body>

2. Properly Closed Elements

Empty elements must include a closing slash. 

<br />

3. Perfect Nesting Hierarchy

Tags must be nested in the correct order. 

<b><i>bold italic</i></b>
