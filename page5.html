HTML Attributes

What are HTML Attributes?

HTML attributes provide additional information about HTML elements.

Attributes are always specified in the start tag.

Attributes usually come in name/value pairs like: name="value"

1. href Attribute

The href attribute specifies the destination URL or path of a hyperlink.

<a href="https://www.itmbu.ac.in">
    Visit ITMBU
</a>

2. src Attribute

The src attribute defines the path of an image.

<img src="img_girl.jpg">

3. width and height Attributes

The width and height attributes specify the dimensions of an image in pixels.

<img src="img_girl.jpg"
     width="500"
     height="600">

4. alt Attribute

The alt attribute provides alternate text for an image if the image cannot be displayed.

<img src="img_girl.jpg"
     alt="Girl with a jacket">

5. style Attribute

The style attribute is used to define style rules directly within an HTML element.

<p style="color:red;">
    This is a paragraph.
</p>

Important Rules
  • Attributes are written inside the start tag.
  • Attributes usually use name="value" format.
  • Use lowercase attribute names.
  • Use quotes around attribute values.
