HTML Style

1. Style Attribute

The HTML style attribute allows CSS styling rules to be applied directly inside an HTML element.

The style consists of a property and a value separated by a colon and ending with a semicolon.

Example

    <p style="color:red;">I am red</p>
    <p style="color:blue;">I am blue</p>
    <p style="font-size:30px;">I am big</p>

I am red

I am blue

I am big

2. Background Color

The CSS background-color property defines the background color of an HTML element.

Example

    <h1 style="background-color:powderblue;">
        This is a heading
   </h1>

This is a heading 

    <p style="background-color:tomato;">
        This is a paragraph.
   </p>

This is a paragraph.

4. Fonts

The CSS font-family property defines the font used for an HTML element.

Example

        
    <h1 style="font-family:verdana;">
        This is a heading
   </h1>

This is a heading 

    <p style="font-family:courier;">
        This is a paragraph.
   </p>

This is a paragraph.

5. Text Size

The CSS font-size property defines the text size for an HTML element.

Example

    <h1 style="font-size:300%;">
        This is a heading
   </h1>

This is a heading 

    <p style="font-size:160%;">
        This is a paragraph.
    </p>

This is a paragraph.

6. Text Alignment

The CSS text-align property defines the horizontal text alignment for an HTML element.

Example
