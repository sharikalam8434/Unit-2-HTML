Nested HTML Elements

What are Nested HTML Elements?

HTML elements can be nested, meaning they can contain other elements inside them.

Nesting Example

 
<html>
    <body>
        <h1>My First Heading</h1>
        <p>My first paragraph.</p>
    </body>
</html>

Nesting Principles
  • HTML documents consist of nested HTML elements.
  • HTML elements can contain other elements inside them.
  • Tags should be closed in the correct reverse order.

Example

The <html> element is the root element of the HTML document. The <body> element contains the visible page content.
