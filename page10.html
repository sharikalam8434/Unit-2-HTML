HTML Colors

1. Color Names

In HTML, a color can be specified by using a color name.

HTML supports 140 standard color names. 

    <p style="color:Tomato;">Tomato</p>
    <p style="color:DodgerBlue;">DodgerBlue</p>
    <p style="color:MediumSeaGreen;">MediumSeaGreen</p>

Tomato

DodgerBlue

MediumSeaGreen

2. Background Color

You can set the background color for HTML elements using the style attribute. 

     <h1 style="background-color:DodgerBlue;">
         Hello World
    </h1>

4. Border Color

You can set the color of borders in HTML using the style attribute with color values. 

    <h1 style="border:2px solid Tomato;">
        Tomato Border
    </h1>

    <h1 style="border:2px solid DodgerBlue;">
        DodgerBlue Border
    </h1>

    <h1 style="border:2px solid Violet;">
        Violet Border
    </h1>

Tomato Border

DodgerBlue Border

Violet Border
