Formatting and Display

1. HTML Display

You cannot be sure exactly how HTML will be displayed because screen sizes and resized windows can create different results.

Adding extra spaces or empty lines in HTML code does not change how the content is rendered.

Browsers automatically collapse multiple spaces and discard line breaks when rendering the page.

Example

This paragraph contains a lot of spaces and lines, but browser ignores it.

2. HTML Horizontal Rules

The HTML <hr> element defines a thematic break in a page, typically displayed as a horizontal line.

It is commonly used to visually separate different content blocks or define transitions.

The <hr> tag is an empty element and has no end tag.

Example

This is heading 1

This is some text.

This is heading 2

This is some other text.

3. HTML Line Breaks

The HTML <br> element defines a manual line break in a web page.

It forces a new line without starting a new paragraph.

The <br> tag is an empty element and has no end tag.

Example

This is
a paragraph
with line breaks.

4. The Poem Problem

Browsers automatically collapse consecutive spaces, tabs, and line breaks in HTML source code into a single space.

The standard <p> element is designed for continuous body text, not for poetic layout.

Example

My Bonnie lies over the ocean. My Bonnie lies over the sea. Oh, bring back my Bonnie to me.

5. The HTML <pre> Element

The HTML <pre> element defines preformatted text.

It preserves spaces and manual line breaks exactly as they are written in the source code.

Text inside a <pre> element is automatically displayed in a fixed-width, monospace font.

Example

 
My Bonnie lies over the ocean.
My Bonnie lies over the sea.
My Bonnie lies over the ocean.
Oh, bring back my Bonnie to me.
