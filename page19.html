Semantic Tags

What are Semantic Tags?

Before HTML5, web page structures mainly relied on generic <div> tags. HTML5 introduced meaningful tags that clearly describe their purpose to developers and browsers.

Key Benefits
  • SEO: Helps search engines understand the page structure and content.
  • Accessibility: Helps screen readers navigate the page structure.
  • Code Readability: Makes the HTML code clean and organized.

Examples of Semantic Tags

 
<header>Page top header</header>

<article>Independent content block</article>

<table>Tabular data representation</table>

<footer>Page bottom section</footer>
