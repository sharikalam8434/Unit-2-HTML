HTML Lists

HTML lists allow web developers to group a set of related items into organized structures.

Unordered HTML List

An unordered HTML list displays items with bullet points.

Example

 
        <ul>
        <li>Coffee</li>
        <li>Tea</li>
        <li>Milk</li>
        </ul>
  • Coffee
  • Tea
  • Milk

Ordered HTML List

An ordered HTML list displays items with numbers.

Example

 
        <ol>
        <li>Coffee</li>
        <li>Tea</li>
        <li>Milk</li>
        </ol>
  1. Coffee
  2. Tea
  3. Milk

HTML Description Lists

A description list contains terms and their corresponding descriptions.

Example

 
    <dl>
        <dt>Coffee</dt>
        <dd>- black hot drink</dd>

        <dt>Milk</dt>
        <dd>- white cold drink</dd>
    </dl>
Coffee
- black hot drink
Milk
- white cold drink
