HTML Document Structure

Basic Structure of an HTML Document

 
<!DOCTYPE html>
<html>
<head>
    <title>Page Title</title>
</head>
<body>
    <h1>My First Heading</h1>
    <p>My first paragraph.</p>
</body>
</html>

Important Parts

1. <!DOCTYPE html>

Defines that the document is an HTML5 document.

2. <html>

It is the root element of an HTML page.

3. <head>

Contains meta information about the HTML page.

4. <title>

Specifies the title shown in the browser's title bar or tab.

5. <body>

Contains all the visible contents of the webpage, such as headings, paragraphs, images and hyperlinks.

6. <h1>

Defines a large heading.

7. <p>

Defines a paragraph.
