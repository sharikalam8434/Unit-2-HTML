Meta Tags

What are Meta Tags?

Meta tags provide essential metadata to browsers, search engines, and web services inside the <head> element.

1. Charset

Defines character encoding and ensures emojis and accents render correctly. 

<meta charset="UTF-8">

2. Viewport

Enables responsive web design by scaling pages for mobile screens. 

<meta name="viewport" content="...">

3. Description

Provides a page summary used directly by Google in search results. 

<meta name="description" content="...">

4. Author

Specifies the author of the document. 

<meta name="author" content="Your Name">

5. Refresh

Refreshes the page automatically every 30 seconds. 

<meta http-equiv="refresh" content="30">
