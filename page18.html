7. HTML Forms

7.1 HTML Forms

An HTML form is used to collect user input, which is most often sent to a server for processing.

7.2 The form Element

The <form> element is a container used to house and coordinate multiple user input components.

  • Text Fields & Areas
  • Checkboxes & Radios
  • Submit Buttons

7.3 The input Element

The <input> element can be displayed in many ways depending on its type attribute.

  • type="text" - Single-line text input field
  • type="radio" - Radio button for selecting one option
  • type="checkbox" - Checkbox for multiple choices
  • type="submit" - Button to submit form data

7.4 Text Fields

The <input type="text"> defines a single-line input field for user text input.

<form> <label>First name:</label>
<input type="text" name="fname">
<label>Last name:</label>
<input type="text" name="lname"> </form>



7.5 The label Element

The <label> element provides a label for an input. The for attribute must match the id of the target input.

7.6 Radio Buttons

The <input type="radio"> defines a radio button, allowing selection of ONE option from a set.

7.7 Checkboxes

The <input type="checkbox"> defines a checkbox, letting a user select ZERO or MORE options.

7.8 Submit Button

The <input type="submit"> defines a button for submitting the form data to a form-handler.
