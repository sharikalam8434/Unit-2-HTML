HTML Images

Images can improve the design and appearance of a web page.

The <img> tag is used to embed an image in a web page.

src Attribute

The required src attribute specifies the precise URL or directory path to the target image resource. 

<img src="IMG_20260926_102120.jpg" alt="Daigram 1">

alt Attribute

The required alt attribute provides fallback text when an image cannot be viewed. 

<img src="IMG_20260926_101924.jpg" alt="Daigram 2">

Image Width and Height

The style attribute can define the width and height of an image.

Width and height attributes can also define the size in pixels. 

  <img src="IMG_20260926_101924.jpg"
         width="300"
         height="200">

Image as a Link

To use an image as a link, place the <img> tag inside the <a> tag. 

  <a href="default.asp">
        <img src="smiley.gif"
             alt="HTML tutorial"
             style="width:42px;height:42px;">
  </a>

Common Image Formats
  • APNG - .apng
  • GIF - .gif
  • ICO - .ico, .cur
  • JPEG - .jpg, .jpeg, .jfif, .pjp
  • PNG - .png
  • SVG - .svg
